# Kaspi Product Card App (Delphi 12.1)

Простое desktop-приложение на Delphi 12.1 (VCL) для заполнения карточки товара и генерации JSON-файла для дальнейшей загрузки/интеграции в процессы Kaspi магазина.

## Функциональность

- ввод ключевых полей карточки товара:
  - название
  - SKU/артикул
  - бренд
  - категория
  - цена
  - количество
  - описание
- ввод произвольных характеристик в формате `ключ:значение`
- предпросмотр итогового JSON
- сохранение JSON в файл

## Структура

- `KaspiCardApp.dpr` — стартовый файл проекта
- `MainForm.pas` — логика формы и генерации JSON
- `MainForm.dfm` — визуальная форма

## Сборка в Delphi 12.1

1. Откройте `KaspiCardApp.dpr` в Delphi 12.1.
2. Нажмите **Run** (F9) для запуска.
3. Заполните поля и нажмите **Сформировать JSON**.
4. Для сохранения нажмите **Сохранить JSON в файл**.

## Пример характеристик

```text
Цвет:черный
Вес:1.2 кг
Материал:металл
```
